# Learning Loop 🔄

This project serves as a practical playground to deeply learn and master native Angular while building a unique UI.

An interactive, highly creative platform to write and store personalized technical blogs. Built to break away from standard, uniform blog layouts and provide a unique visual and reading experience for each post.

## Stack

- Angular (Native SPA)
- pnpm (Package Manager)
- Vanilla CSS for 3D UI Effects

## Development Server

Run `ng serve` for a dev server. Navigate to `http://localhost:4200/`.

## Installation

You must use `pnpm` for this project.

```bash
pnpm install
```
